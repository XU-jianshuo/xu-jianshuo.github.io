# 数字简历 DESIGN.md 风格应用设计

日期：2026-08-04  
状态：已确认视觉方向，待实施

## 1. 目标

将已克隆的 `awesome-design-md` 设计规范应用到当前数字简历网站，使站点从原有暖橙编辑画报风格，收敛为更适合金融保险、精算、风险管理履历的克制专业界面。

目标体验：

1. 第一屏清楚传达“徐建硕”和财产保险经营、精算、风控的专业定位。
2. 页面视觉更像专业工作台和履历文档，减少装饰感。
3. 保持中文长文、项目专题和英文页面的可读性。
4. 保留现有内容、链接结构、图片资源和静态站点架构。

## 2. 参考规范

本轮采用 `awesome-design-md` 中的两套 DESIGN.md：

- `awesome-design-md/design-md/linear.app/DESIGN.md`
- `awesome-design-md/design-md/notion/DESIGN.md`

应用方式：

- 以 Linear 为主：近黑画布、炭灰面板、细边框、蓝紫色稀缺强调、紧凑按钮和卡片圆角。
- 以 Notion 补充：中文正文可读性、浅色页面兼容、清晰的信息卡片和文档式节奏。

## 3. 视觉规则

### 3.1 色彩

- 主画布：近黑或深炭灰，不使用纯黑。
- 信息面板：使用分层炭灰或浅灰面板，通过 1px hairline 区分层级。
- 强调色：蓝紫色，只用于主按钮、链接、焦点环、关键编号和少量状态标记。
- 取消当前大面积暖橙主色，红橙仅保留给必要的风险或警示语义。

### 3.2 字体与排版

- 使用系统 sans 字体栈，中文优先，保持跨平台稳定。
- 标题使用 600-700 字重，行距紧凑。
- 正文保持 1.6 左右行高，避免深色背景下阅读疲劳。
- 不使用 viewport-width 直接缩放字体，采用 `clamp()` 固定上下限。

### 3.3 组件形态

- 按钮统一 8px 圆角，避免胶囊按钮泛滥。
- 卡片统一 8-12px 圆角，减少 28px、42px 这类过大圆角。
- 卡片以细边框和 surface ladder 表达层级，减少大阴影。
- 标签和资质可继续使用 pill 形态，但颜色更克制。

## 4. 范围

### 4.1 包含

- 在项目根目录新增 `DESIGN.md`，记录本项目采用的设计规则。
- 更新 `assets/css/tokens.css` 的设计 token。
- 调整 `assets/css/base.css`、`assets/css/components.css`、`assets/css/pages.css` 中与首页、通用卡片、导航、专题页相关的视觉样式。
- 保持现有页面内容、路由、图片和 JavaScript 行为不变。
- 运行现有站点测试。

### 4.2 不包含

- 不重写网站内容。
- 不新增前端框架或构建系统。
- 不引入远程字体依赖。
- 不改 GitHub Pages 发布配置。
- 不把 `awesome-design-md/` 作为当前网站源码的一部分提交。

## 5. 验收标准

1. 根目录存在项目级 `DESIGN.md`，能说明采用的 Linear/Notion 规则。
2. 首页第一屏、能力卡片、履历时间线、近期工作卡片、联系区的视觉语言一致。
3. 中文和英文页面均能继续打开，导航、主题切换和锚点不被破坏。
4. 移动端布局仍为单列或可横向滚动的稳定布局，不出现文字溢出。
5. `npm test` 或项目现有测试命令通过；如因环境缺失无法运行，需要记录原因。
