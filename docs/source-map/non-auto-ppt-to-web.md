## 视觉映射原则

- PPT 中的业务地图转成可响应的 HTML 场景导航与场景矩阵。
- PPT 中的经营闭环转成六步连续流程，手机端改为纵向序列。
- PPT 中的产品经营卡统一为可筛选的网页卡片。
- PPT 中的落地动作转成四阶段路线图。
- PPT 中的风险提示使用独立红线区域，不与一般经营建议混排。
- PPT 中的时间和目标转成推进路线与指标看板，避免只用段落描述。
